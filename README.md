# SLODAT 🩸

A modern blood donation platform connecting donors with hospitals to make blood donation faster, easier, and more accessible.

## Overview

SLODAT is a healthcare platform designed to bridge the gap between blood donors and hospitals. The platform helps users discover donation opportunities, manage donor information, and support hospitals during blood shortages.

## Features

### Donor Features
- Create and manage donor profiles
- View donation requests
- Track donation activity
- Access personal dashboard

### Hospital Features
- Create hospital accounts
- Request blood donations
- Manage donor responses

### Platform Features
- Responsive design
- Secure authentication
- Modern dashboard interface
- Mobile-friendly experience
